## 一、交付范围与依赖顺序

本轮交付六类护甲的生成、实例保存、角色背包、装配与卸下、地面生成与拾取、限时丢出分享、奖励事件防重，以及支撑这些操作的世界身份、房主权限与结束清理。

容量按每槽位背包 12 件计算，不包含身上装备，不跨槽位借用容量。九槽整体规划 108 件；本轮六个护甲分区最多 72 件。仓库按玩家共享、容量 300，仅保留规则，本轮不提供仓库 UI、查询或存取接口。

不实现武器实例与生成、任务系统、特殊词条、品阶掉落概率、权威战斗验证、后端六维生效与实时冷却。内部预留直接发背包能力，任务来源装备不具备分享资格。

建议顺序：接入核对 → 契约与数据结构 → 护甲生成及背包装配 → 世界权限 → 奖励事件 → 地面流转 → 游戏联调 → 验收。背包与生成的独立工作不必等待全部联机细节确定，但正式发奖依赖有效世界和稳定事件身份。
