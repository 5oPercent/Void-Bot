## 一、交付范围与依赖顺序

本轮交付六类护甲的生成、实例保存、角色背包、装配与卸下、地面生成与拾取、限时丢出分享、奖励事件防重，以及支撑这些操作的世界身份、房主权限与结束清理。

角色背包总容量为 120 件，所有装备类别共享，各槽位不设独立上限，已穿装备不计入。本轮护甲已可使用全部 120 个位置，未来武器接入共用同一上限。仓库按玩家共享、容量 300，仅保留规则，本轮不提供仓库 UI、查询或存取接口。

不实现武器实例与生成、任务系统、特殊词条、权威战斗验证、后端六维生效与实时冷却。用户后续确认奖励来源包括任务、杀敌、开箱，并要求可配置奖励池；本批实现来源触发概率、池内装备／品阶权重及内部背包发放，不预设正式概率数值。任务来源装备不具备分享资格。

建议顺序：接入核对 → 契约与数据结构 → 护甲生成及背包装配 → 世界权限 → 奖励事件 → 地面流转 → 游戏联调 → 验收。背包与生成的独立工作不必等待全部联机细节确定，但正式发奖依赖有效世界和稳定事件身份。
